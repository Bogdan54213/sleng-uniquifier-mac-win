Sleng Унікалізатор

Інструкція зі встановлення для macOS

macOS 12 Monterey і новіше
1
Визнач свій Mac
  1. Клікни на (яблуко) у верхньому лівому куті екрану
  2. Вибери "About This Mac"
  3. Подивись на рядок "Chip" або "Processor":

  • 🔵 Apple M1 / M2 / M3 / M4 → завантажуй файл mac-dmg-arm64
  • 🔵 Intel Core i5 / i7 / i9 → завантажуй файл mac-dmg-x64
2
Відкрий та встанови додаток
  1. Двічі клікни на завантажений файл SlengUniquifier_v1.0.0_xxx.dmg
  2. Відкриється вікно з іконкою додатку
  3. Перетягни Sleng Uniquifier у папку Applications
  4. Дочекайся завершення копіювання
3
Перший запуск (важливо!)
  1. Відкрий Finder → зліва клікни Applications
  2. Знайди Sleng Uniquifier
  3. Клікни правою кнопкою миші на додатку → вибери "Open"
  4. З'явиться попередження — клікни "Open" ще раз
⚠️ Увага: Не відкривай подвійним кліком при першому запуску — тільки через правою кнопку миші → Open. Це обійде захист macOS Gatekeeper.
4
Якщо кнопки "Open" немає — Privacy & Security
  1. Відкрий System Settings (Системні налаштування)
  2. Вибери розділ Privacy & Security
  3. Прокрути вниз — побачиш повідомлення про Sleng Uniquifier
  4. Клікни "Open Anyway"
  5. Введи пароль свого Mac → натисни Enter
5
Якщо нічого не допомогло — Terminal
  1. Натисни Cmd + Space → напиши Terminal → натисни Enter
  2. Встав наступну команду і натисни Enter:
xattr -cr "/Applications/Sleng Uniquifier.app"
  1. Після цього відкривай додаток звичайним подвійним кліком
6
Реєстрація та активація
  1. При першому запуску з'явиться форма реєстрації
  2. Введи своє ім'я та контакт (Telegram або email)
  3. Натисни "Відправити заявку"
  4. Очікуй активаційний код від адміністратора
  5. Після отримання коду — натисни "У мене є код"
  6. Введи код та натисни "Активувати"
  7. Готово — додаток відкриється!
✅ Все готово! Якщо виникли проблеми зі встановленням — напиши адміністратору в Telegram.
